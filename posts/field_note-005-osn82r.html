슬라이드 7, 원본 USB와 언론 버전 사이의 숨은 차이

한 장의 메모가 전체 이야기를 바꿨다.

내가 처음 USB를 받았을 때, 파일 리스트에 눈에 띈 건 “PRISM_7_2013‑06‑10.bin”이었다. SHA‑256 해시값은 **a3f9c2d5e6b7f8a9c0d1e2f3b4a5c6d7e8f9a0b1c2d3e4f5a6b7c8d9e0f1a2b3** 로, 공개된 스크린샷과는 미세하지만 확실히 다른 값이었다. 😊

언론에 나온 슬라이드 7은 “전략적 데이터 수집 포인트”라는 캡션 아래, 3줄의 표만 보여줬다. 원본 파일을 열어보면, 같은 표 위에 **‘Error Code 0x8009000F – Key Material Corrupted’** 라는 오류 메시지가 숨겨져 있었다. 이는 해당 시점에 암호화 키가 손상돼 일부 데이터가 복구 불가능했음을 의미한다. 🧐
